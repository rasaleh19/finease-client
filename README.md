FinEase - Personal Finance Management App
Live Site URL: https://dapper-cat-541615.netlify.app/
A modern, full-stack financial management application built with React and Express, featuring seamless authentication and transaction tracking capabilities.
Key Features

Dual Authentication System: Supports both manual email/password registration and Google OAuth sign-in with Firebase Authentication, ensuring secure user access and profile management across sessions
Real-time Transaction Management: Add, track, and manage financial transactions with instant updates, powered by a robust Express backend and MongoDB database for reliable data persistence
Modern UI with DaisyUI & Tailwind CSS: Beautiful, responsive interface built with Tailwind CSS utility classes and DaisyUI components, providing an intuitive user experience across all devices
Cloud-Deployed Architecture: Backend API hosted on Vercel with MongoDB Atlas for scalable database management, while the frontend is deployed on Vercel for lightning-fast performance and global CDN distribution
Persistent User Profiles: Automatic profile synchronization with custom photo URLs and display names, ensuring user data consistency whether signing up manually or through Google authentication

Tech Stack
Frontend: React, React Router, Tailwind CSS, DaisyUI
Backend: Express.js, MongoDB
Authentication: Firebase Auth
Deployment: Vercel (Frontend & Backend), MongoDB Atlas
